\section{摂動計算の基礎}

\subsection{多数の変数に支配される統計と摂動計算の一般論}
いま，$N$個の確率変数$X = \qty(X_1, \cdots, X_N)$に支配される確率分布を考える．
確率分布$P(X)$は次の形で与えられるとする．
\begin{align}
  P(X) = \frac{e^{-S[X]}}{Z}.
\end{align}
ここで，$S[X]$は$X$の何らかの関数である（具体形は指定しない）．
また，$Z$は規格化定数であって次の形式を持つ．
\begin{align}
  Z = \int \qty[\dd X] \, e^{-S[X]}
   := \int \dd X_1 \cdots \int\dd X_N \, e^{-S[X]}.
\end{align}
この状況下で，ある量$O(X)$の期待値$\ev{O(X)}$とは
\begin{align}
  \ev{O(X)} = \int \qty[\dd X] \, O(X) e^{-S[X]}
           := \int \dd X_1 \cdots \int \dd X_N \, O(X) e^{-S[X]}
\end{align}
である．
いま，$S[X]$を$X$の2次形式であらわせる部分とそれ以外の部分に分解し，それぞれ$S_0[X]$と$S_\mathrm{int}[X]$と書くことにする．
\begin{align}
  S[X] = S_0[X] + S_\mathrm{int}[X].
\end{align}
このような分解は2次形式を指数関数の肩に乗せたものが解析的に計算が可能であるという事実に動機付けられるものである．
この分解を行うと実質的に任意の確率分布の下での期待値を正規分布の下での期待値に読み替えることができる：
\begin{align}
  \ev{O(X)} = \int \qty[\dd X] \, O(X) e^{-S[X]}
            = \int \qty[\dd X] \, O(X) e^{-\qty(S_0[X] + S_\mathrm{int}[X])}
            = \int \qty[\dd X] \, \qty{O(X) e^{-S_\mathrm{int}[X]}} e^{-S_0[X]}.
\end{align}

いま，この結果を用いて次のように摂動計算を行うことができる．
正規分布の下での期待値の計算は複雑な確率分布の下での計算よりずっと易しい．
基本的な考え方は単に$e^{-S_\mathrm{int}[X]}$を級数展開するのみである．
\begin{align}
  \ev{O(X)} = \int \qty[\dd X] \, O(X) \sum_{k = 0}^{\infty}\frac{\qty(-S_\mathrm{int}[X])^k}{k!} e^{-S_0[X]}
            \sim \int \qty[\dd X] \, O(X) e^{-S_0[X]} - \int \qty[\dd X] \, O(X) S_\mathrm{int}[X] e^{-S_0[X]} + \cdots
\end{align}
である．
最右辺をどう計算するかが問題であるが正規分布の下で少々複雑な量の期待値を計算することに帰着されたので問題は大幅に簡略化されたといえる．

以上が摂動的場の理論の根幹をなす考え方である．
物理学者は$X = \qty(X_1, \cdots, X_N)$の添え字を連続に拡張し$X = \qty(X_x); \, x\in \mathbb{R}^n$に対して同様な計算手法を構築した．
それが経路積分である．
経路積分は次のように表記されることが多い．
\begin{align}
  Z = \int \mathscr{D}X \, e^{-S[X]}, \quad \ev{O(X)} = \int \mathscr{D}X \, O(X) e^{-S[X]}.
\end{align}

\subsection{ウィックの定理}
以降では簡単のため，実スカラー場の理論を例にとって考える．
自由場の理論は次で与えられる．
\begin{align}
  S_0[\varphi] = \frac{1}{2}\int \dd^4x \, \varphi(x) \qty(-\partial^2 + m^2) \varphi(x).
\end{align}
準備として次の公式を与えておく．
\begin{align}
  \varphi(x) e^{-S_0[\varphi]} = \int \dd^4y \, \varDelta(x - y) \frac{\delta}{\delta \varphi(y)} e^{-S_0[\varphi]}, \quad 
\end{align}
この理論の下での場の積の期待値は一般に
\begin{align}
  \ev{T \Big\{\varphi(x_1) \cdots \varphi(x_n)\Big\}}_0 = \frac{1}{Z} \int \mathscr{D} \varphi \, \varphi(x_1) \cdots \varphi(x_n) e^{-S_0[\varphi]}
\end{align}
である．

\subsection{自由スカラー場のプロパゲーターの計算}
自由スカラー場のプロパゲーターは次で定義される．
\begin{align}
  \ev{T\Big\{\varphi(x)\varphi(y)\Big\}}_0 = \frac{1}{Z}\int \mathscr{D} \varphi \,\varphi(x)\varphi(y) \exp(-S_0[\varphi]), \quad S_0[\varphi] := \frac{1}{2}\int \dd^4x \, \varphi(x) \qty(-\partial^2 + m^2) \varphi(x)
\end{align}
計算上の利便のため，$\varphi$ をフーリエ変換しておく．
自由場の作用は
\begin{align}
  S_0[\varphi] &= \frac{1}{2}\int \dd^4x \, \varphi(x) \qty(-\partial^2 + m^2) \varphi(x) = \frac{1}{2}\int \dd^4x \, \int_p \tilde{\varphi}(p) e^{ipx} \qty(-\partial^2 + m^2) \int_q \tilde{\varphi}(q) e^{iqx} \notag \\
  &= \frac{1}{2}\int_p \int_q \tilde{\varphi}(p) \tilde{\varphi}(q) \qty(q^2 + m^2) \int \dd^4x \, e^{i(p + q)x} = \frac{1}{2}\int_p \int_q  \tilde{\delta}(p+q) \qty(q^2 + m^2) \tilde{\varphi}(p) \tilde{\varphi}(q) \notag \\
  &= \frac{1}{2}\int_p  \qty(p^2 + m^2) \tilde{\varphi}(p) \tilde{\varphi}(-p)
\end{align}
の変換を受ける．
よって，プロパゲーター自体は
\begin{align}
  \ev{T\Big\{\varphi(x)\varphi(y)\Big\}}_0 &= \frac{1}{Z}\int \mathscr{D} \tilde{\varphi} \, \int_p \tilde{\varphi}(p)e^{ipx} \int_q \tilde{\varphi}(-q)e^{iqy} \exp{-\frac{1}{2}\int_k  \qty(k^2 + m^2) \tilde{\varphi}(k) \tilde{\varphi}(-k)} \notag \\
  &= \frac{1}{Z}\int_p e^{ipx} \int_q e^{iqy} \int \mathscr{D} \tilde{\varphi} \, \tilde{\varphi}(p) \tilde{\varphi}(-q) \exp{-\frac{1}{2}\int_k  \qty(k^2 + m^2) \tilde{\varphi}(k) \tilde{\varphi}(-k)}.
\end{align}
である．
\footnote{スカラー場が実である条件 $\tilde{\varphi}(p) = \tilde{\varphi}(-p)$ を用いている．}
奇関数の性質を用いると $p = -q$ の場合以外は，これは有限の値を持たないことが直ちにわかる．
よって，結局のところ
\begin{align}
  \ev{T\Big\{\varphi(x)\varphi(y)\Big\}}_0 &= \frac{1}{Z}\int_p  e^{ipx}  \int_q  e^{iqy} \int \mathscr{D} \tilde{\varphi} \, \tilde{\varphi}^2(p)\exp{-\frac{1}{2}\int_k  \qty(k^2 + m^2) \tilde{\varphi}^2(k)} \tilde{\delta}(p + q) \notag \\
  &= \int_p  e^{ipx}  \int_q  e^{iqy} \, \tilde{\delta}(p + q) \int \mathscr{D} \tilde{\varphi} \, \tilde{\varphi}^2(p)\exp{-\frac{1}{2}\int_k  \qty(k^2 + m^2) \tilde{\varphi}^2(k)} \notag\\
  &= \int_p  e^{ipx}  \int_q  e^{iqy} \,  \frac{1}{p^2 + m^2} \cdot \tilde{\delta}(p + q) = \int_p \frac{e^{ip(x - y)}}{p^2 + m^2}
\end{align}
とフーリエ空間で展開できる．
