\section{有限温度の量子色力学}
まず，有限温度の場の理論，特に，有限温度における量子色力学（qunatum chromodynamics；QCD）を概観する．
この節は我々が扱おうとしている物理，つまり，クォーク・グルーオン・プラズマ（quark-gluon plasma；QGP）の物理がいかなるものであるかを明らかにするために当てられる．

\subsection{経路積分形式による統計力学}
ある系に対してハミルトニアン $H$ が与えられると分解関数 $Z$ を定義することができ，（原理的には）様々な物理量を計算することができる．
$Z$ は
\begin{align}
  Z = \Tr e^{-\beta H} \label{def:pf}
\end{align}
と定義される．
経路積分の方法を用いて $Z$ を表示することもできる．
この場合にはハミルトニアンではなくラグランジアンが主役になる．
そのためには分配関数の定義 \eqref{def:pf} を次のように書き直してみる．
\begin{align}
  Z = \Tr e^{-\beta H} = \sum_\varphi \bra{\varphi} e^{-\beta H} \ket{\varphi}
\end{align}

この修士論文のプロジェクトの過程では数多くのツールが用いられたが，ここでは特にコンピューターに関連する優れたツールに注目したい．
論文の入手，スーパーコンピューター上での数値シミュレーションプログラムの実行，本修士論文の執筆のすべては Linux カーネルの存在なしにはなしえなかったことだ．
インターネットを支えるウェブサーバー，数値シミュレーションを行ったスーパーコンピューター，論文の執筆を行ったラップトップ，そのすべてで，多少の固有最適化はあれど基本的には同じカーネルが動いている．
それだけではない．組み込みシステムでも使われている．Android フォンのカーネルも Linux である．有人ロケット，人工衛星に載って宇宙にも行った．コンピューター業界が長年探し求める，クロスプラットフォームという聖杯を我々は手にしている．

Linux カーネルは 1991 年に Helsinki 大学の計算機科学専攻の学生であった Linus Torvalds が趣味のプロジェクトとしてそれを創始した．
現在では世界中に数千人の開発者がいる．
現在では Torvalds が書いたコードは Linux カーネルのソースコードのうちのごく一部でしかなく，ほかの開発者の貢献なしに我々がその利便性を経験することができないのは確かだが，もっと重要ななの Torvalds がそれを創始したということだ．
彼に最大限の敬意と感謝を表する．
